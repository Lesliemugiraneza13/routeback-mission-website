RouteBack presentation summary

1) shared/css/variables.css
This file defines CSS custom properties, also called design tokens, for the site’s colours, spacing, fonts, shadows, and layout sizes. It uses :root to make those values available everywhere, and it also has a dark-theme version that overrides them when the page switches themes. This is better than hardcoding values in many places because the design stays consistent and is much easier to update.

2) shared/css/main.css
This file is the main stylesheet entry point. It imports the other CSS files in a specific order: variables first, then base, layout, patterns, components, sections, and utilities. Load order matters because later files can override earlier ones, and the variables file must be loaded early so everything else can use those custom properties.

3) index.html
This page uses CSS Grid and Flexbox to create a clean, modern layout. The hero section uses a two-column grid, the quick planner form uses grid-based rows for its fields, and the feature cards and benefit sections use flexbox to arrange content neatly. These layout techniques help the page stay responsive and easy to read on different screen sizes.

4) assets/js/index.js
This script makes the home page’s quick planner actually work. When the page is ready, it fills the dropdowns, updates the time label when the journey mode changes, and sends the selected options to the planner page when the form is submitted. In simple terms, it turns the static form into a working path from the homepage to trip planning.

5) shared/js/theme.js
This script controls the light and dark theme toggle. Clicking the button switches the theme, saves the choice in local storage so it is remembered later, and updates the page’s data-theme attribute. That attribute then lets the CSS custom properties in variables.css change the whole site’s colours, so the theme feels consistent across the page.
